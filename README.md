# Keystone Property Group

Static marketing website for Keystone Property Group, in a black and cream/beige theme.

Services: Water (plumbing, leak detection, damp and environmental surveys), Security (alarms, sensors, CCTV), Home Audio and Entertainment, and General Home Improvements.

## Run locally

Open `index.html` in a browser, or run `npx serve .`.

The contact form currently uses a placeholder `mailto:` address. Replace it in `index.html`.
