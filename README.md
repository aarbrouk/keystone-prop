# Keystone Property Group

Static marketing website for Keystone Property Group, with a clean blue theme and subtle animations.

The landing page has a tile for each service, each linking to its own mini-site:

- `/water` (plumbing, leak detection, damp and environmental surveys)
- `/bathrooms` (full installations, toilets, baths, basins, showers, tiling)
- `/security` (alarms, sensors, CCTV)
- `/entertainment` (home cinema, entertainment systems)
- `/general` (repairs, refurbishments, upgrades)
- `/roofing` (repairs, replacements, maintenance)

## SEO

- Every page has its own title, description, canonical URL, Open Graph tags and JSON-LD structured data.
- `/areas/` and the pages under it target the two-hour radius around Bournemouth. They are generated by `node build-areas.js`, which also writes `sitemap.xml` and `robots.txt`. Edit the `places` list in that file and re-run it to add or change areas.
- Before launch, replace `https://www.keystonepropertygroup.co.uk` (in `build-areas.js` and the `<head>` of each page) with the real domain, and replace the placeholder email address.

## Run locally

Run `npx serve .` and open the printed address so the `/water`-style paths work.

The contact form currently uses a placeholder `mailto:` address. Replace it in `index.html`.
